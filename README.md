# Lezda — Jeu Action-Aventure 3D Rétrogaming

Projet développé dans le cadre du concours **Games on Web 2027 (CGI)** en partenariat avec Université Côte d'Azur et Université Aix-Marseille.

---

## 🎮 Concept du Jeu

**Lezda** est un jeu d'action-aventure 3D en vue isométrique/zénithale, hommage vibrant aux premiers jeux d'aventure rétro façon *The Legend of Zelda*.

Le joueur incarne un héros armé d'une simple épée dans une mini-plaine centrale dotée de 3 voies :
1. **Le Chemin Ouvert (Est) :** Une première caverne d'initiation avec énigme et combat basique, permettant de récupérer la première clé.
2. **Le Chemin Verrouillé (Ouest) :** Un sanctuaire gardé nécessitant la première clé, renfermant la Clé du Boss.
3. **La Porte du Boss (Nord) :** L'épreuve finale face au Gardien de Pierre, ouvrant l'accès à la victoire.

---

## 🛠️ Stack Technique

* **Moteur 3D :** Babylon.js (moteur exclusif imposé par le règlement du concours)
* **Frontend :** HTML5 / CSS3 / JavaScript (Vite en bundler de développement)
* **Audio :** Web Audio API (effets sonores et ambiances rétro chiptune)
* **Direction Artistique :** Low-poly rétro, textures pixel-art nettes (`NEAREST_SAMPLINGMODE`), 60 FPS constants.
